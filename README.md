# Join Our Newsletter

A clean and responsive newsletter subscription page built as part of a DevChallenges challenge.

## Features

- **Responsive Design:** Optimized for various screen sizes (desktop, tablet, mobile).
- **Modern UI/UX:** Built with a clean aesthetic, custom Google Fonts ("Poppins"), and soft drop shadows.
- **Interactive Elements:** Includes hover and active states for buttons and styled focus rings for input fields.
- **Semantic HTML5:** Uses proper semantic tags (`<main>`) for better accessibility and SEO.

## Built With

- HTML5
- CSS3 (Flexbox, Media Queries, Custom Gradients)
- Google Fonts (Poppins)

## Getting Started

To run this project locally, follow these simple steps:

1. **Clone or Download** this repository to your local machine.
2. Open the project folder in your favorite code editor (like **VS Code**).
3. Open the `index.html` file directly in your browser, or use an extension like **Live Server** in VS Code to preview it live.
